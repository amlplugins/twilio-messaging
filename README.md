# @amlplugins/twilio-messaging

Native `twilio` SDK re-exported under the `@amlplugins` namespace.

> Twilio Programmable Messaging — SMS, MMS, WhatsApp via Messaging Services.

## Install

```bash
npm install @amlplugins/twilio-messaging
```

## Use

```ts
import { /* named exports from twilio */ } from "@amlplugins/twilio-messaging";
// or
import sdk from "@amlplugins/twilio-messaging";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
